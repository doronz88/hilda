# API Reference

Generated from the `hilda` source. Hilda is driven through a `HildaClient` (the `p` global in the shell); symbols and Objective-C objects are the values you work with.

- **[HildaClient](https://doronz88.github.io/hilda/latest/api/client/index.md)** — the main client and its methods.
- **[Symbols & Objective-C](https://doronz88.github.io/hilda/latest/api/symbols/index.md)** — the `Symbol` object and ObjC class support.
- **[Breakpoints & watchpoints](https://doronz88.github.io/hilda/latest/api/breakpoints/index.md)** — breakpoint/watchpoint handles and registers.
- **[Exceptions](https://doronz88.github.io/hilda/latest/api/exceptions/index.md)** — Hilda's exception types.
